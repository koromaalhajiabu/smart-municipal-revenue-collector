# SmartMunicipal Revenue Collector

Field levy collection app for Freetown City Council. Installable on Android and iPhone, works offline, and syncs to Supabase when online.

## Files
- `index.html`: the app (collector and admin views)
- `manifest.webmanifest`: install metadata
- `sw.js`: service worker for the offline app shell
- `icons/`: app icons, generated by `make_icons.py`
- `make_icons.py`: regenerates the icons with no dependencies

## Hosting
Serve the folder over HTTPS (for example Netlify Drop, Vercel or Cloudflare Pages). Installation and offline mode require HTTPS.

## Before live use
- Replace the demo collector PINs with Supabase Auth sign-in.
- Replace the sample taxpayer register in the Supabase `taxpayers` table with the council's data.
- Do not put a secret or service-role key in `index.html`. Only the publishable key belongs there.

## Database
The Supabase schema lives in `supabase/migrations/` and is applied in filename order:
- `20261019200900_create_municipal_schema.sql`: taxpayers, collectors, transactions, row-level security, sample data
- `20261019210100_add_admin_access.sql`: admin accounts and their read access
